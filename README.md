# Software Portfolio

카메라·LiDAR 같은 센서 데이터를 받아 **영상의 기하를 맞추고, 실시간으로 처리하고, 결과를 검증하는** 소프트웨어 프로젝트 모음입니다.
각 프로젝트는 **문제와 원인 → 해결 과정 → 결과** 순서로 정리했습니다.

| 프로젝트 | 한 줄 요약 | 주요 기술 |
|---|---|---|
| [**카메라·LiDAR 융합 자율주행 시스템**](./autonomous-driving) | 1/10 스케일 차량에서 카메라·LiDAR 인식부터 경로 생성, 조향·속도 제어까지 연결한 ROS 2 주행 소프트웨어 | Python · ROS 2 · OpenCV · PyTorch · OpenVINO |
| [**특징점 기반 파노라마 스티칭**](./panorama-stitching) | OpenCV 없이 NumPy로 코너 검출부터 호모그래피 추정, 워핑·블렌딩까지 구현한 N장 파노라마 생성기 | Python · NumPy · PIL |

## 두 프로젝트에서 공통으로 다룬 문제

| 주제 | 자율주행 | 파노라마 |
|---|---|---|
| **영상 기하** | 렌즈 왜곡 계수와 장착 각도로 지면 호모그래피를 계산하고, BEV 셀마다 원본 픽셀을 역으로 찾아가는 remap 테이블 구성 | 대응점으로 Normalized DLT 호모그래피를 추정하고, 역방향 워핑과 Bilinear 보간으로 공통 좌표계에 투영 |
| **이상치·오검출 처리** | CNN 경로를 제어에 넘기기 전에 유효점 수·길이·기울기·곡률로 검사하고, 장애물은 연속 프레임으로 확인 | 이동벡터 중앙값 필터와 RANSAC 뒤에 면적·원근·방향·중심 순서로 호모그래피를 다시 검증 |
| **입력 전처리·품질** | 학습과 실차의 입력 전처리를 통일해 센서 채널의 의미를 맞춤 | 사진별 평균 밝기 Gain 보정, 감마 보정, Feathering 블렌딩 |
| **검증** | 녹화 데이터를 원래 시간 간격으로 재생하는 Replay 환경과 단위 테스트 | 실패 사례 사진 세트로 수정 전후를 비교 |
